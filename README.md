# 📐 Math Text to Word Converter

A web platform that converts mathematical exercises, series, and assignments generated by AI tools such as ChatGPT, Claude, or DeepSeek into clean and professionally structured Word documents.

## 🚀 How It Works

1. **Copy** your mathematical exercise, series, or assignment from an AI tool.
2. **Paste** the content into the platform.
3. **Preview** the formatted text and mathematical equations.
4. **Generate** your `.docx` file.
5. **Download** a clean, structured Word document ready to use.

The platform automatically detects and formats mathematical equations, LaTeX syntax, Markdown headings, and common mathematical symbols.

## ✨ Features

- 📝 Automatic Markdown cleanup and formatting
- 📐 LaTeX and mathematical equation detection
- π Conversion of Unicode mathematical symbols
- 🔧 Automatic fixing of common LaTeX syntax errors
- 🎯 Proper equation rendering in Word using MathML
- ⚡ Fast and fully local text processing
- 💯 No manual formatting required

## 🛠️ Tech Stack

- **Frontend:** React, Next.js, TypeScript, Tailwind CSS, KaTeX
- **Backend:** Next.js API Routes, Node.js
- **Processing:** Pandoc, Remark
- **Deployment:** Netlify
